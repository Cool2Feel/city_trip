## 修正：bake.yml 部署方式改为官方 Actions 模式（解决「Source 无 gh-pages 选项」）
- 原部署步用 `peaceiris/actions-gh-pages@v4` 推 `gh-pages` 分支，属「Deploy from a branch」方式，**必须 gh-pages 分支已存在**才会在 Pages Source 下拉出现。用户反馈下拉里没有 gh-pages 选项（因为该分支还没创建/推送）。
- 已改为官方 Actions 部署模式：删除 peaceiris 步骤，替换为 `actions/upload-pages-artifact@v3` + `actions/deploy-pages@v4`；workflow 级加 `permissions: pages: write, id-token: write`；job 加 `environment: name: github-pages`。
- 效果：**不再依赖任何分支**。用户需在仓库 Pages 设置 Build and deployment → Source 选 **「GitHub Actions」**（独立选项，非 Deploy from a branch），而非选具体分支。YAML 复校通过（9 steps，environment=github-pages）。
