## v4.0 深度优化：真实API + 标记聚类 + 离线缓存策略

### 1. 真实 REST API 后端 (server/)
- 新建 Express 服务器 `server/index.js`，7个REST端点：/cities, /cities/:code, /cities/hot, /reports/:code, /places/:code, /cities/:code/center, /weather/:code
- 服务器直接 require miniprogram/utils/mockData.js 作为数据源，无需重复维护数据
- 包含 CORS 中间件、请求日志、模拟网络延迟(50-200ms)
- 标准响应包：`{ success, data, source, timestamp, serverTime }`
- 健康检查端点 /v1/health + API统计端点 /v1/stats

### 2. api.js v4.0 增强
- **Stale-While-Revalidate (SWR)**: 缓存过期时立即返回stale数据，后台异步刷新，用户零等待
- **差异化TTL**: cities(24h) > center(30d) > report(2h) > places(6h) > weather(1h)
- **手动刷新**: 所有API方法支持 `forceRefresh=true` 参数绕过缓存
- **LRU缓存淘汰**: 超过50条/2048KB时按 hitCount×recency 评分淘汰最旧条目
- **请求去重**: 并发相同请求共享一个Promise，避免重复网络调用
- **指数退避重试**: 服务器错误/网络失败自动重试2次，延迟500ms→1s→2s
- **Auth拦截器**: 自动注入 Bearer token，401时清除token
- **离线兜底**: API+Cloud都失败时，返回过期缓存（标记offline=true）
- **缓存状态报告**: getCacheStatus() 返回条目数/大小/命中次数/按类型统计

### 3. 地图标记聚类 (clusterHelper.js)
- **网格聚类算法**: 按zoom级别动态调整gridSize (zoom≤10: 0.08°, zoom≥15: 不聚类)
- **缩放级别响应**: bindregionchange 事件监听，throttle 200ms 重新聚类
- **聚类标记**: 显示"N个地点"气泡，按数量分 small(<5)/medium(5-9)/large(≥10) 三级
- **点击聚类放大**: 聚类marker点击后自动zoom in到13-15级展开个体标记
- **统计面板**: 顶部提示"共N个地点，已聚合为M个标记"
- 与分类筛选/搜索联动：筛选后重新聚类

### 四、代码健康问题修复

#### 问题9：LRU缓存淘汰不生效
- **根因**：`cache._store` Map 从未被写入——`get()` 直接从 `wx.storage` 读，`set()` 只写 storage，因此 `_evictIfNeeded()` 的条件 `this._store.size >= 50` 永远为 false
- **修复**：新增 `_syncFromStorage()` 惰性同步方法，首次访问时从 storage 历史条目加载到内存 Map
- `set()` 同时写入 `_store` Map 和 `wx.storage`，`get()` 先查内存 Map（快速路径）再回退 storage
- `_evictIfNeeded()` 和 `_evictOldest()` 现在能正确工作
