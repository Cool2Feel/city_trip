🎯 已实现的核心功能

🏙️
城市选择
支持10个热门城市，搜索+热门推荐，城市切换后自动加载报告数据
⚙️
10步工作流可视化
完整展示10步标准化调研流程，含步骤状态、耗时、详情，支持模拟生成动画
📋
10节标准报告
一图速览→活动清单→优惠门票→喜茶→美食街→CityWalk→地铁→路线→时效说明→API统计
🗺️
11类地图标记
分类配色系统（演唱会红/球赛紫/集市黄...），支持筛选、搜索、卡片联动
🛤️
3条周末路线
文艺青年/情侣浪漫/亲子家庭，每条路线含完整时间表与地点导航
🔍
质量保障闭环
5维度质量检查（完整性/准确性/丰富度/可执行性/信源多样性）+ 补查询迭代记录
📊
API调用统计
透明展示每批次搜索的query、并行数、耗时、返回结果数
📚
11方向分类浏览
每个调查方向独立详情页，含时效性标注、Query关键词、信源标注
⭐
收藏与本地存储
城市收藏、报告保存、缓存管理，支持wx.storage本地持久化

📁 项目文件结构

miniprogram/
├── app.js                          # 应用入口，全局数据与存储管理
├── app.json                        # 全局配置，tabBar 4页导航
├── app.wxss                       # 全局样式，CSS变量系统（含11类配色）
├── project.config.json            # 项目配置
├── sitemap.json                   # 小程序索引配置
├── assets/tab/                     # tabBar图标（8个PNG）
├── utils/
│   ├── categories.js              # 11个调查方向配置（名称/配色/图标/Query）
│   ├── mockData.js                # Mock数据（3城市完整报告+地图标记点）
│   └── util.js                    # 辅助函数（日期/Toast/距离计算等）
├── pages/
│   ├── home/                       # 首页：城市选择+概览+亮点+快捷入口
│   ├── discover/                   # 发现：10步工作流+质量检查+API统计
│   ├── map/                        # 地图：11类标记+筛选+搜索+联动
│   ├── profile/                    # 我的：收藏+报告+设置+关于
│   ├── city-select/               # 城市选择：搜索+热门+全部
│   ├── report/                     # 报告：10节结构展开/折叠展示
│   ├── category/                   # 分类：11方向独立详情页
│   └── route/                      # 路线：A/B/C三线+时间线
# 共 8个页面 × 4文件 + 3个工具 + 配置 = 45个文件

📖 如何在微信开发者工具中运行

  • 下载并安装 微信开发者工具（稳定版）
  • 打开微信开发者工具，选择「导入项目」
  • 项目目录选择：D:\dwl\work\todo\city_trip（包含 project.config.json 的目录）
  • AppID 可选择「测试号」或填入自己的小程序 AppID
  • 点击确定后，开发者工具会自动编译并预览
  • 支持「真机调试」扫码在手机上查看效果

💡 数据说明

  • 当前使用 Mock 数据，已预置 广州/深圳/成都 3个城市的完整报告数据
  • 每个城市包含：10节报告 + 3条周末路线 + 11类地图标记点 + 质量检查 + API统计
  • 广州有 39 个地图标记点，深圳 11 个，成都 13 个
  • 数据来源标注真实（大麦网/小红书/大众点评等），但具体信息为演示数据
  • 接入真实后端 API 后，替换 utils/mockData.js 即可切换为实时数据
