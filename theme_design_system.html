周末城市游 · 主题图片设计系统

基于「11方向调研 · 10节标准报告 · 3条周末路线」的视觉识别体系，为微信小程序提供统一、温暖、可识别的品牌视觉语言。

🎯 品牌标识

App 图标采用城市天际线剪影 + 定位标记的组合，传递「城市探索」与「周末出行」的核心价值。

设计说明

  • 城市天际线融合传统建筑与现代高楼，体现中国城市的古今交融
  • 暖橙到紫红的日落渐变，营造周末傍晚的轻松氛围
  • 白色定位标记突出「发现城市」的产品定位
  • 圆角矩形符合 iOS/Android 应用图标规范
  • 文件路径：miniprogram/assets/images/logo.png

📱 应用场景

主题图片已集成到小程序各页面，明确每张图片的使用位置与尺寸建议。

首页 Hero 背景

使用 home-banner.png，通过深色渐变遮罩叠加，确保 Slogan 与按钮文字清晰可读。

周末路线封面

路线页顶部展示 coverImage，切换 A/B/C 路线时图片与颜色同步变化。

分享卡片

可截取 Logo + 当前城市一图速览生成分享图，强化品牌识别。

启动页/加载页

Logo 可作为启动图标与加载动画中心元素，配合 Slogan 使用。

🔧 集成说明

图片已存放于 miniprogram/assets/images/，并在 mockData.js 与页面样式中完成引用。

// mockData.js 中每条路线新增 coverImage 字段
{
  id: 'A',
  name: '文艺青年线',
  color: '#7b1fa2',
  coverImage: '/assets/images/route-art.png',
  desc: '博物馆+CityWalk+市集，文化深度体验'
}

<!-- route.wxml 中展示路线封面 -->
<image wx:if="{{activeRoute.coverImage}}"
       class="route-cover"
       src="{{activeRoute.coverImage}}"
       mode="aspectFill" />

/* home.wxss 中将 banner 设为 Hero 背景 */
.hero-bg {
  background: linear-gradient(...), url('/assets/images/home-banner.png') center/cover no-repeat;
}
